# 🚀 MeetSphere - AI Powered Video Conferencing Platform

A modern full-stack video conferencing platform built with the MERN Stack, WebRTC, and Socket.IO. MeetSphere enables seamless real-time communication with secure authentication, video meetings, screen sharing, live chat, and AI-powered assistance.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/SoumyaPratap/MeetSphere-Video-Conferencing-Platform.git
```

### Install Dependencies

Frontend

```bash
cd frontend
npm install
npm run dev
```

Backend

```bash
cd backend
npm install
npm start
```
